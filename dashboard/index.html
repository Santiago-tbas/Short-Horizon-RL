Simulation Parameters

Boundary Formula:

c_T = √((2 * σ² * ln(T)) / (η * T))

Epsilon (ε*) is the largest gap where consecutive sorted sub-optimality gaps satisfy:

Δ_{i+1} - Δ_i ≤ c_T
